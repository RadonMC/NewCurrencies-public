## Summary

Modrinth (max 256 characters) and CurseForge (max 250):

```
Euro coins and banknotes for Minecraft, plus an ATM that withdraws and deposits them against your server economy (EconomyCraft, Common Economy API). Fabric and NeoForge.
```
