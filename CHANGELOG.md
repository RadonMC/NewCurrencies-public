# Changelog

Versions are shared by Fabric and NeoForge. Each file is named `newcurrencies-<version>+<minecraft>.jar`.

## 1.1.1

- Updated the homepage and issue tracker links to the public repository.

## 1.1.0

- Added the **ATM**: a two-block-tall machine to withdraw coins and banknotes from your account and deposit them back. Right-click it to open the menu.
- The ATM works with economy mods: on Fabric any mod that implements the Common Economy API (bundled, nothing to install) and EconomyCraft, on NeoForge EconomyCraft.
- Added `config/newcurrencies.json` to choose the economy provider and currency.
- Added an Italian translation.
- First release for **NeoForge 26.x** (Minecraft 26.1.x, 26.2 and 26.3).

## 1.0.0

- Port to Minecraft 26.1.x, 26.2 and 26.3 (Fabric).
